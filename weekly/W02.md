## 本周做了什么
- 写了BMI计算机，学会了什么是float，即：length_float=float(length)就是将输入的数字文本转换为带小数点的数字
- 验证了计算结果
- 建了公开仓库
- 学习了python的if elif else语句：从if开始看条件是否符合，若不成立则下到下一个elif,最终有else兜底
- 学习了python的try except语句：我理解是用try来标定程序中可能因输入数据错误而导致无法接下的程序；后面的except ValueError后跟的就是当发生前面错误是接下程序的“接盘侠”代码，可以来防止程序崩溃，但仅限一次try:
    这里放"可能出事"的代码
except ValueError:
    print("出事了怎么办")
- 为了解决上面的try except语句无法抵御多次程序错误，从而学习了while True语句：它重要的语言包括while True和break,前者是用来进行无数次循环的，后者是当满足正确程序进行后停止循环的。例如：while True:
    text = input("提示语: ")
    try:
        value = float(text)
        break                    # 合格 → 放行，跳出循环
    except ValueError:
        print("不是数字，请重新输入")   # 没放行 → 自动回到开头，再问一次
- 学到了程序在终端运行时常见的语言：异常/exception 抛出/raise 接住/catch 追溯/traceback ~^~是用来只是精确的错误地址

    length = input(...)        ← ①里
    try:                       ← ② 异常保护盒

    except ValueError:         ← ②的搭档
        print("提示")
